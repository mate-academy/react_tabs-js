# React Tabs (JS)

Реализуй компонент `Tabs`, который отображает несколько вкладок и позволяет пользователю переключаться между ними.

> Здесь можно посмотреть [рабочую версию](https://mate-academy.github.io/react_tabs).

Компонент `App` должен взаимодействовать с компонентом `Tabs` с помощью следующих пропсов:

- `tabs` — массив объектов вкладок, которые должен отобразить компонент `Tabs`;
- `activeTabId` — `id` вкладки, которая должна быть активной;
- `onTabSelected` — функция обратного вызова, которая вызывается с `id` только что выбранной вкладки, когда пользователь нажимает на неё.

Компонент `Tabs` не должен иметь состояния (то есть у него не должно быть внутреннего состояния — только пропсы).

Чтобы тесты прошли успешно, выполни следующие требования:

1. Отобрази вкладки в виде списка (`<ul>`).
2. Каждый элемент `<li>` должен иметь атрибут `data-cy="Tab"`.
3. Элемент `<li>` активной вкладки должен иметь класс `is-active`.
4. Если `activeTabId` не соответствует ни одному объекту в массиве `tabs`, активной должна стать первая вкладка.
5. Внутри каждого `<li>` добавь ссылку с атрибутом `data-cy="TabLink"` и значением `href`, равным `#tab-id` (смотри разметку).
6. Компонент `Tabs` должен отображать содержимое активной вкладки в элементе с атрибутом `data-cy="TabContent"`.
7. Вызывай `onTabSelected` только тогда, когда пользователь выбирает неактивную вкладку.
8. Используй заголовок активной вкладки в элементе `<h1>` компонента `App` в следующем формате: `Selected tab is Tab 1`.
